# [Advanced Duplicator 2](https://steamcommunity.com/sharedfiles/filedetails/?id=773402917)

Рекомендую прочитать оригинальную документацию к этому аддону:
https://github.com/wiremod/advdupe2/wiki

## Чем он лучше обычного дубликатара

- Сохранение всех предметов на определённой области
- Авто сохранение построек
- Есть почти на каждом сервере
- Лучше работает со сложными постройками
- Вставка на изначальную позицию
- Может создавать маленькие дубликаты через wiremod
